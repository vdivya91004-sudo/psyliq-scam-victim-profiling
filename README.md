# PSYLIQ Investigative Data Analysis Internship

## Project 1: Scam Execution & Victim Profiling

### Project Overview

This project analyzes U.S. cybercrime victim demographics, scam tactics, and government response using data analysis and visualization techniques.

### Objectives

- Analyze cybercrime victim demographics
- Identify common scam tactics and patterns
- Explore trends in scam execution
- Analyze government response and enforcement
- Generate meaningful insights from the available data

### Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite
- Excel
- Jupyter Notebook

### Project Files

- `Psyliq_P1_Scam_Profiling.ipynb` – Complete Python data analysis and visualization
- `Data_Matrix_P1.xlsx` – Project data matrix
- `Final_Report_P1.pdf` – Final project report
